What it is

Codex Advisor is an open-source, skills-only plugin that provides disciplined second opinions for material technical decisions. When your root agent faces a complex architectural trade-off, an interface design, a data-model migration, or competing root-cause diagnoses, Advisor consults a fresh, read-only advisor before code gets written.

Advice is non-authoritative. The root agent reviews it against repository evidence and explicitly records whether the recommendation was accepted, modified, or rejected.

The plugin runs entirely on your machine. There is no hosted service, no MCP server, and no telemetry — consultation never leaves your local Codex runtime and its existing connection to OpenAI.

How it works

01 — Triggering

Disciplined, not chatty

Consults on architecture, interface, and compatibility choices; work spanning module, trust, process, or persistence boundaries; competing root-cause diagnoses; and irreversible state, migration, security, and privacy decisions. Factual lookups, mechanical edits, doc formatting, and settled plans skip automatically.

02 — Role selection

Two risk-calibrated tiers

Standard (advisor-terra, GPT‑5.6 Terra, high effort) handles general architecture, interface design, data modeling, and generic second-opinion requests. Specialist (advisor-sol, GPT‑5.6 Sol, high effort) is reserved for unresolved security or trust boundaries, irreversible migration or data-loss decisions, and credible high-severity disagreement.

03 — Isolation

Read-only, zero tools

Every consultation runs in a forced read-only sandbox with zero tools enabled. The advisor does not read files you did not send it, does not call tools, and does not browse the web. A runtime inspector verifies the child's provenance, model, effort, and isolation before any result is returned.

04 — Receipts

Visible in main chat

ADVISOR CALL records the tier, role, reason, bounded question, and status before launch. ADVISOR RESULT records the verified model, high effort, read-only isolation, the recommendation, and the root agent's disposition. A skipped or unavailable preflight emits only ADVISOR DECISION.

05 — Fallback

Research-first, never a guess

When the packet lacks the evidence to choose, the advisor does not invent one. It returns a concrete research-first next step and names the missing evidence under FOLLOW-UP AREAS.

06 — Failure mode

Fail closed

Missing, conflicting, or malformed runtime evidence records route: unavailable with no consultation process started — and never blocks the work your root agent already owns.

Install

Add the marketplace, install the plugin, then run the companion installer resolved from the installed plugin directory:

# 1. Add the marketplace repository
codex plugin marketplace add dave-schmidt-dev/advisor --ref main

# 2. Install the plugin
codex plugin add advisor@advisor

# 3. Run the companion installer
plugin_dir="$(codex plugin list --json | jq -r '.installed[] | select(.pluginId == "advisor@advisor") | .source.path')" && test -n "$plugin_dir" && test "$plugin_dir" != null && test -d "$plugin_dir" && test -f "$plugin_dir/scripts/install-agents.sh" && sh "$plugin_dir/scripts/install-agents.sh"

Start a new Codex thread after installation so the skill and custom roles are discovered. Eligible decisions match implicitly; you can also ask explicitly:

Use $advisor:consultation for a fresh, read-only second opinion on this decision.

Verify a local installation without starting Codex or making a network call:

sh plugins/advisor/scripts/verify.sh --static

Compatibility

Codex Advisor is a Codex-only plugin built for local development workflows.

SurfaceStatusDetail
Codex CLISupportedRuns through your local Codex CLI runtime on macOS or Linux.

Generic ChatGPT aloneUnsupportedPreflight returns route: unavailable and no transport is invoked.
Native Codex subagentsUnsupported as transportSubagents inherit parent permissions and cannot supply the required read-only isolation contract.
MCP servers and hosted servicesOut of scopeThe plugin operates with no MCP server and no hosted service.

Local prerequisites

Consultation requires all of the following on the machine running Codex. When any one is absent, the plugin records route: unavailable rather than degrading.

  • Codex CLI or Codex desktop.
  • jq available in $PATH.
  • A POSIX shell (sh).
  • An active persisted Codex session rollout.
  • A resolvable CODEX_THREAD_ID. CODEX_SESSION_ID is never used as a fallback.
  • An OpenAI account with model availability for gpt-5.6-terra and gpt-5.6-sol at high reasoning effort.

Privacy in one paragraph

Consultation packets stay inside your local Codex session and your own authenticated connection to OpenAI. No prompts, code, or context are transmitted to the maintainers, to Zero Delta LLC, or to any third-party infrastructure. Receipts and transcripts live in your local persisted Codex session logs, which the plugin never uploads or copies. The bundled local audit tool reports aggregate counts only and redacts code, prompts, filenames, paths, and identifiers. Full detail is in the privacy policy.
