Codex Advisor

Automatic read-only advice for material Codex decisions, with smart defaults and optional models. It advises; your main agent decides.

Install from OpenAI View source

What it does

  1. Finds the decision.Architecture, interfaces, migrations, security, or competing diagnoses.
  2. Challenges it read-only.The advisor gets a bounded packet, no tools, and no write access.
  3. Returns the call.Your main agent accepts, changes, or rejects the recommendation.

The consultation child is verified read-only and tool-free. Direct invocation of installed advisor profiles is unsupported.

Choose your models

Advisor uses the live advisor.toml bundled with the installed plugin. The defaults are Terra at high effort for Standard and Sol at high effort for Specialist.

[standard]
model = "gpt-5.6-terra"
effort = "high"

[specialist]
model = "gpt-5.6-sol"
effort = "high"

# Optional: gpt-6-astra uses more of your Codex allowance.

Edit the bundled advisor.toml in place and the change applies to the next consultation. Standard and Specialist have independent effort settings. Future model selectors are subject to your account access and runtime support. No setup conversation or separate canary is required. Plugin updates may replace edits to the bundled file.

Install from OpenAI

Codex Advisor is available in the official OpenAI Plugins Directory.

Open in Plugins Directory

Install it there, then start a new Codex thread so Advisor is available to the session.

Compatibility

Consultations send bounded packets through your own authenticated Codex/OpenAI account; Zero Delta operates no relay, hosted backend, or intermediary service.
