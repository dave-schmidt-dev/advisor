1. Overview and core principles

Codex Advisor is an open-source, skills-only plugin designed for local use within Codex CLI and Codex desktop.

  • Local execution. The plugin operates entirely on your own machine. There is no hosted service and no remote backend infrastructure.
  • No third-party transmission. No prompts, code snippets, project context, or consultation packets are transmitted to the maintainers, to Zero Delta LLC, or to any third-party infrastructure.
  • No telemetry or analytics. The plugin includes no telemetry, no analytics tracking, no crash reporting, and no MCP server.
  • Zero-tool sandboxing. Advisor child processes run in a forced read-only sandbox with zero tools enabled, which prevents outbound network connections and unsolicited local file modification.

2. Information handled by the plugin

Local consultation context

When the root agent invokes a consultation, it compiles a bounded five-section packet containing the technical decision question, and the relevant code context, architectural options, and repository boundaries that the root agent chose to supply. The packet is not intended to carry credentials, secrets, personal data, or unrelated conversation history.

That packet is processed locally by your authenticated Codex runtime through your existing OpenAI subscription. Communication with OpenAI is governed by your own OpenAI account agreement and OpenAI's privacy policy. Codex Advisor interposes no proxy, no intermediate server, and no hosted service.

Local session data

  • Consultation activity, receipts (ADVISOR CALL and ADVISOR RESULT), and decisions are recorded locally within your persisted Codex session logs.
  • Those logs remain on your own storage under your configured Codex home directory, for example ~/.codex/sessions.
  • The plugin never uploads, copies, or shares persisted Codex session logs.

3. Local audit and diagnostic script

The repository includes a local audit utility, plugins/advisor/scripts/advisor-audit.sh, for inspecting consultation metrics.

  • It operates strictly on local persisted Codex session logs.
  • It calculates aggregate counts and statistics, such as consult and skip counts and token totals.
  • It enforces strict redaction: it never emits session content, user prompts, file paths, filenames, identifiers, contact information, secret-shaped patterns, or cost calculations.
  • Its output is written to local standard output and is not transmitted anywhere.

4. Authentication and credentials

Codex Advisor relies exclusively on your existing local Codex host authentication. The plugin does not request, collect, store, transmit, or handle OpenAI API keys or login credentials, and it does not read or duplicate credential files from your environment.

5. Third-party services and surfaces

  • OpenAI Codex. Consultation requests execute via your local Codex installation communicating with OpenAI models (gpt-5.6-terra and gpt-5.6-sol). Data handling by OpenAI is governed by OpenAI's terms.
  • No MCP or hosted service. Codex Advisor provides no MCP server, no hosted service, and no background cloud service.

6. User control and data deletion

Because all consultation data resides solely in local persisted Codex session logs on your own machine, you retain complete ownership and control. You may inspect, modify, archive, or delete those logs at any time using standard operating system tools. Removing or uninstalling the plugin removes the plugin files from your environment without affecting your repository data.

7. This website

This site is a set of static pages served from Zero Delta LLC's own hosting. It sets no cookies, loads no third-party scripts or fonts, and runs no analytics or tracking. The hosting provider keeps standard web server access logs, which contain the IP address, timestamp, requested path, and user agent of each request, for operational and security purposes.
